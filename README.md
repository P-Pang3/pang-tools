# 트릭스터 매크로

트릭스터 온라인 **사설 서버**용 보조 도구 세 가지. Windows 전용.

| 프로그램 | 하는 일 | 크기 |
|---|---|---|
| **줍기 매크로** | 화면에서 아이템을 찾아 자동으로 줍는다 | 219 KB |
| **사냥 매크로** | 스킬로 몬스터를 잡고 물약을 쓴다 | 219 KB |
| **오토 클릭** | 정해진 간격으로 마우스·키를 반복 입력한다 | 79 KB |

셋은 독립 프로그램이다. 필요한 것만 받아 쓰면 된다.

> 공식 서버나 상용 게임에는 쓰지 말 것. 사설 서버라도 운영 규칙은 서버마다
> 다르므로, 쓰기 전에 그 서버의 정책을 확인하는 것은 사용자 몫이다.

---

## 설치

1. [Releases](../../releases) 에서 원하는 프로그램의 `*-full.zip` 을 받는다
2. 아무 데나 풀고 `... 실행.bat` 을 두 번 누른다
3. 처음 한 번만 필요한 것을 자동으로 설치한다 (인터넷 필요)

Python 이 없다면 [python.org](https://www.python.org/downloads/) 에서 받아
설치한다. 설치할 때 **"Add python.exe to PATH"** 를 반드시 체크해야 한다.

새 버전이 나오면 프로그램을 켤 때 위쪽에 알림 띠가 뜬다. 누르면 받아서
적용하고 스스로 다시 시작한다. **설정과 템플릿은 그대로 남는다.**

---

## 줍기 매크로

화면에서 아이템 이미지를 찾아 마우스를 옮기고 클릭한다.

1. **템플릿** 탭 → `새 템플릿 캡처` → 게임 화면에서 아이템을 드래그로 선택
2. **실행** 탭 → `시작` (또는 `Home`)

찾은 것이 맞는지 보려면 `🔎 오버레이` 를 켠다. 검출 박스와 점수가 화면에
그려지므로 임계값을 눈으로 보고 맞출 수 있다.

한 번 클릭한 대상은 사라질 때까지 지켜본다. 세 번 시도해도 그대로면
20초 동안 건너뛴다 — 벽 너머 아이템을 영원히 클릭하지 않게.

## 사냥 매크로

줍기에 더해 몬스터를 공격하고 물약을 쓴다.

1. **템플릿** 탭에서 몬스터를 캡처하고 **종류를 `몬스터`** 로
2. **설정** 탭 → **⚔ 사냥** → `사냥 모드 사용` 체크
3. **체력 바 `영역 지정`** → 게임 HP 바 안쪽을 드래그 (가득 찬 상태에서)
4. 공격 스킬과 물약 키를 지정

동작 우선순위는 이 순서로 고정이다.

```
사망 · HP 위험  →  정지
HP / MP 부족    →  물약
몬스터 있음      →  공격
아이템 있음      →  줍기
```

HP 가 바닥인데 아이템을 주우러 가면 죽으므로, **회복은 언제나 전투보다
먼저다.** 공격은 `스킬키 → 대상 클릭` 순서로 나가고, 스킬 세 개를
쿨다운에 맞춰 돌려 쓴다.

체력 바를 지정하지 않으면 물약도 위험 정지도 동작하지 않는다.

## 오토 클릭

게임과 무관하게 쓸 수 있다. 간격(ms), 마우스 버튼, 키, 반복 횟수,
클릭 위치(커서 자리 / 고정 좌표)를 정한다. 마우스와 키를 함께 쓸 수도 있다.

## 멈추는 방법

| 방법 | 언제 |
|---|---|
| `Home` | 시작 / 정지 |
| `F12` | 비상 정지 |
| **마우스를 화면 왼쪽 위 모서리로** | 단축키가 안 들을 때. 즉시 멈춘다 |

이 밖에도 마우스를 직접 만지면 잠시 물러나고, 게임 창이 사라지면 스스로
정지한다.

---

## 알아둘 것

- **관리자 권한**: 게임이 관리자로 실행 중이면 매크로도 관리자로 실행해야
  한다. 아니면 마우스는 움직이는데 클릭이 안 먹는다
- **해상도**: 템플릿은 캡처한 해상도에서만 맞는다. 해상도를 바꿨다면 다시
  캡처해야 한다
- **백신**: 매크로 + 자동 업데이트 조합을 의심하는 백신이 있다

## 폴더

```
프로그램폴더/
  실행.bat
  app/     프로그램 코드. 업데이트가 이 폴더만 갈아끼운다
  data/    설정·템플릿·로그. 업데이트해도 그대로다
```

다른 PC 로 옮길 때는 `data/` 만 복사하면 설정이 따라간다.

## 개발

```bash
python main.py --pickup      # 줍기
python main.py --hunt        # 사냥
python autoclick.py          # 오토 클릭

python build.py              # dist/ 에 배포본 생성
python release.py 1.1.0 -m "변경 내용"   # 빌드 + GitHub 릴리스
```

소스는 한 곳에 두고 `build.py` 가 프로그램마다 필요한 모듈만 골라 담는다.
자세한 것은 [DEPLOY.md](DEPLOY.md) 를 볼 것.

### 구조

```
main.py        줍기·사냥 GUI (실행 인자로 갈린다)
autoclick.py   오토 클릭 (독립)
engine.py      GUI 와 core 사이 어댑터
core/
  perception/  화면 스캔 — ROI · 빠른거부 · 피라미드 · 다중검출
  tracking.py  대상 추적 — 시도 이력과 성공 판정
  combat.py    전투 판단 — 우선순위 규칙
  vitals.py    HP/MP 판독 — 색 픽셀 비율
  actuation.py 입력 — 지연 분포 · Fitts 이동 · 오버슛
  safety.py    페일세이프 · 개입 감지 · 워치독
  updater.py   GitHub 릴리스 자동 업데이트
```

### 테스트

```bash
python tests/test_detection.py    # 검출 정확도
python tests/test_safety.py       # 안전 장치 11종

python tests/test_update.py       # 업데이트 로직 15종
python tests/test_autoclick.py    # 오토 클릭 9종
python tests/bench_detection.py   # 스캔 속도
```

콘솔이 CP949 라 로그의 이모지에서 죽는다. `PYTHONIOENCODING=utf-8` 을 붙여
실행할 것.
